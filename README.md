## Welcome Message

Welcome to my personal playground and daily journal for mastering the Rust programming language! This repository tracks my journey from foundational syntax to complex algorithms, data structures, and memory safety concepts.

## Repository Structure

The code is organized in folders. So each folder is like a complete project or solution that I may have worked on.

To run a specific Package:
    ```
        cargo run -p <package-name> e.g cargo run -p pig_latin
    ```
